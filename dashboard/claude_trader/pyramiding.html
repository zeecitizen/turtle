The pyramiding EA

The same trades as our main gold robot (Saad 15-min v1.18). The difference: when a trade starts going our way, this version adds more to it, step by step, up to about 3 lots. More profit on strong moves, bigger losses on reversals.

Each add-on is 0.75 × the previous one ("an upright pyramid": most of the size sits at the earliest, best price). Total at most about 3.05 lots.

The rules, step by step

  1. The base trade is exactly the main EA's trade: same setups (pin bar, marubozu, hammer on the 9 / 50 EMA), same stop 35 pips beyond the candle, same 50% close at the first target and $2 trailing stop.
  2. The price moves 0.25 × ATR in our favour beyond the last entry (ATR = the average 15-minute candle size; about $1.50–2 on normal days) → add 0.75 × the last position.
  3. Repeat until there are 5 positions in total.
  4. Every add-on carries the base trade's stop, and follows it as the base trade's stop moves (breakeven at 75% of the way to the target, then the $2 trail).
  5. When the base trade closes, every add-on closes with it. Add-ons in loss are also closed 3 minutes before the daily close.
  6. No breakeven lock when adding. Tested: pulling all stops to the average entry on each add-on wiped out most of the profit.

Every order's comment names the EA: Saad15-PYR3 v1.01 BUY / SELL for the base trade, Saad15-PYR3 v1.01 ADD for add-ons. You can always see in MetaTrader where a trade came from.

The honest trade-off

Bigger swings, both ways

It holds up to about 3 lots, so a bad day is about 3× a bad day of the plain EA (−$12k to −$13k on a $25k account). It needs that capital and the margin.

Plain extra lots are slightly better per $ of risk

The plain EA at about 3 lots would make about +$607k for the same drawdown. Pyramiding adds size late, at worse prices, which costs more on reversals. This version exists because Zee chose it.

Run it alone, or with its own magic

It uses magic number 88330, so it won't touch the plain EA's trades (88302). Don't run two copies with the same magic on one account: they adopt and fight over each other's stops.

How to run it

  1. In MetaTrader (Axi), drag Saad_strategy_15min_pyramiding_max_3 onto an XAUUSD M15 chart.
  2. On the Inputs tab press Reset, so the tested defaults are used.
  3. Check the Experts tab shows [SAAD-PYR3] v1.01 (… ATR x0.25, 5 tiers, x0.75).
  4. Demo account first. Keep Algo Trading on and the PC running: the add-ons and the trailing are managed by the EA, not by the broker.
